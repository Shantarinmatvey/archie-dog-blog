# Дневник Арчи 🐾 (Archie's Golden Retriever Blog SPA)

Полноценный, интерактивный и адаптивный (Desktop + Mobile) сайт-блог на русском языке про золотистого ретривера по имени **Арчи**. Реализован в виде автономного **Single Page Application (SPA)** на нативных веб-технологиях (HTML5, CSS3, ES6+ JavaScript) без внешних фреймворков и бэкенда.

---

## 🎨 Дизайн и концепция (UI/UX)
- **Стиль:** Скандинавский теплый минимализм, ощущение уюта, простора и воздуха.
- **Цветовая палитра:**
  - Фон страницы: мягкий кремовый/льняной (`#FAF7F2`) с легкими декоративными акцентами.
  - Карточки и модальные окна: чистый белый (`#FFFFFF`) с мягкими глубокими тенями (`box-shadow: 0 8px 30px rgba(0, 0, 0, 0.04)`).
  - Акценты: карамельно-медовые (`#D48C46`, `#C27B35`, `#F9EFE4`).
  - Текст: глубокий графитово-кофейный (`#2C2623`) для заголовков, приглушенный теплый серый (`#7A726D`) для второстепенного текста.
- **Типографика:** Элегантный антиквенный шрифт с засечками **Lora** для заголовков и чистый гротеск **Plus Jakarta Sans** для интерфейса.
- **Скругления:** Мягкие современные углы (`20px`–`24px` для карточек и модалок, `999px` для pill-кнопок).

---

## 📱 Кроссплатформенность и адаптивность
- **Десктоп (ПК / Ноутбуки):** Центрированный контейнер 1060px, журнальная двухколоночная сетка ленты, верхняя навигация с быстрым поиском.
- **Мобильные устройства:** Одноколоночная лента на 100% ширины с отступами 16px, крупные сенсорные области (touch-target от 44px), компактная шапка с выдвижным поиском и плавающая кнопка быстрого добавления записи (`FAB`).

---

## 🚀 Реализованный функционал

1. **Шапка сайта (Header):**
   - Логотип «Дневник Арчи 🐾» с анимацией виляющей лапки.
   - Поиск по текстам историй в реальном времени с подсветкой и кнопкой быстрой очистки.
   - Кнопка «+ Добавить» / «+ Создать запись».
   - Навигация: Главная, Галерея, Обо мне.

2. **Профиль питомца (Hero-секция):**
   - Круглый аватар Арчи со статусом («На связи 🌿»).
   - Имя, порода, возраст, био/статус.
   - **Живые счетчики:** количество публикаций и суммарное количество «лапок» (лайков), пересчитываемые в реальном времени.
   - **Редактирование профиля:** модальное окно с мгновенным изменением имени, возраста, породы, статуса и загрузкой новой аватарки.
   - **Паспорт Арчи:** отдельная карточка с любимыми вкусностями, игрушками, повадками и днем рождения.

3. **Создание публикаций (Инлайн-виджет + Модальное окно):**
   - Текстовое поле с быстрой панелью эмодзи (`🐾`, `🦴`, `🐶`, `🍂`, `🌾`, `🎾`, `💤`, `❤️`, `✨`).
   - Выбор типа: «Фотография», «Видеоролик» или «Только текст».
   - Загрузка файлов через Drag-and-Drop или выбор на диске (FileReader Data URL), а также прямая ссылка (URL).
   - Превью и возможность удаления/замены до публикации.
   - Валидация и мгновенная вставка в начало ленты.

4. **Лента публикаций (Feed):**
   - Фильтры: «Все», «Только фото 📸», «Только видео 🎥», «Любимые 🐾».
   - **Фото-карточки:** масштабирование `object-fit: cover`, микроанимация легкого зума при наведении, открытие в полноэкранном **Lightbox** по клику.
   - **Видео-карточки:** кастомный HTML5 плеер с большой центральной кнопкой Play, прогресс-баром в карамельном цвете с перемоткой, индикатором звука и полноэкранным режимом.
   - **Реакция «🐾 Дай лапу!»:** интерактивная кнопка с сохранением статуса и микроанимацией всплывающих лапок.
   - **Комментарии:** раскрывающийся список, добавление нового комментария в реальном времени с фиксацией времени.
   - **Удаление записи:** диалог подтверждения с удалением из ленты и пересчетом статистики.

5. **Полноэкранный просмотр (Lightbox):**
   - Темный полупрозрачный фон с эффектом blur, просмотр фото в максимальном разрешении, закрытие по клику на фон, крестик или клавишу `Escape`.

6. **Хранение данных:**
   - Все изменения, посты, реакции и профиль сохраняются в `localStorage`.
   - Если хранилище пустое — лента автоматически инициализируется строго 2 качественными демо-постами (осенняя пробежка ретривера с фото и субботний сонный потягуш с видео).
   - Кнопка «Вернуть демо-данные» в подвале для быстрого сброса.

## 💻 Как открыть и запустить
1. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari) двойным кликом:
   - Либо через команду: `Start-Process "C:\Users\shant\.gemini\antigravity\scratch\archie-dog-blog\index.html"`
2. Либо запустите встроенный локальный сервер Python:
   ```bash
   cd C:\Users\shant\.gemini\antigravity\scratch\archie-dog-blog
   py -m http.server 8080
   ```
   и откройте `http://localhost:8080` в браузере.

# Рэджи Золотое Сердце 🐾 (Reggie Golden Heart Blog)

Уютный, душевный и адаптивный (Desktop + Mobile) фотодневник золотистого ретривера по имени **Рэджи**. Реализован в виде чистого, быстрого и легкого автономного **Single Page Application (SPA)** на нативных веб-технологиях (HTML5, CSS3, ES6+ JavaScript) с синхронизацией реакций читателей в реальном времени через Firebase Realtime Database.

---

## 🎨 Дизайн и концепция (UI/UX)
- **Скандинавский теплый минимализм:** чистый кремово-льняной фон (`#FAF7F2`), белые парящие карточки с мягкими тенями (`box-shadow: 0 8px 30px rgba(0, 0, 0, 0.04)`), карамельно-медовые акценты (`#D48C46` / `#C27B35`) и глубокий кофейно-графитовый цвет текста (`#2C2623`).
- **Лаконичность и фокус на фотоисториях:** никаких лишних кнопок или перегруженных элементов. Чистые фотокарточки и искренние истории.
- **Типографика:** Элегантный антиквенный шрифт с засечками **Lora** для заголовков и **Plus Jakarta Sans** для интерфейса.

---

## 📱 Кроссплатформенность и адаптивность
- **Десктоп (ПК / Ноутбуки):** Центрированный контейнер 1060px, журнальная сетка ленты, навигация.
- **Мобильные устройства:** Одноколоночная лента на 100% ширины, крупные сенсорные области (touch-target от 44px), поддержка свайпов.

---

## 🚀 Реализованный функционал

1. **Шапка сайта (Header):**
   - Логотип «Рэджи Золотое Сердце 🐾» с анимированной лапкой.
   - Навигация: «Все истории», «Понравившиеся 🐾».

2. **Профиль питомца (Hero-секция):**
   - Круглый аватар Рэджи со статусом («Рэджи на связи 🌿»).
   - Имя, порода и статус питомца.
   - Живые счётчики историй и суммарных лапок.

3. **Инстаграм-карусель в публикациях:**
   - Для дорожных историй с несколькими фото подключена удобная карусель в стиле Instagram.
   - Перелистывание стрелками (`‹` и `›`), сенсорными свайпами на смартфонах и точками-индикаторами.
   - Полноэкранный **Lightbox** при клике на любые фотографии.

4. **Реакции и комментарии в реальном времени:**
   - Интерактивная реакция «🐾 Дай лапу!» со счётчиком, начинающимся с нуля, и анимацией вылетающих лапок.
   - Комментарии читателей с сохранением в Firebase Realtime Database.

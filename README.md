# Дневник Арчи 🐾 (Archie's Golden Retriever Blog SPA)

Полноценный, интерактивный и адаптивный (Desktop + Mobile) сайт-блог на русском языке про золотистого ретривера по имени **Арчи**. Реализован в виде автономного **Single Page Application (SPA)** на нативных веб-технологиях (HTML5, CSS3, ES6+ JavaScript) без внешних фреймворков и бэкенда.

---

## 🎨 Дизайн и концепция (UI/UX)
- **Скандинавский теплый минимализм:** чистый кремово-льняной фон (`#FAF7F2`), белые парящие карточки с мягкими тенями (`box-shadow: 0 8px 30px rgba(0, 0, 0, 0.04)`), карамельно-медовые акценты (`#D48C46` / `#C27B35`) и глубокий кофейно-графитовый цвет текста (`#2C2623`).
- **Лаконичность и простота:** отсутствие лишних кнопок и перегруженных элементов. Чистое текстовое поле и интуитивный плюсик `+` для прикрепления фото и видео.
- **Типографика:** Элегантный антиквенный шрифт с засечками **Lora** для заголовков и **Plus Jakarta Sans** для интерфейса.

---

## 📱 Кроссплатформенность и адаптивность
- **Десктоп (ПК / Ноутбуки):** Центрированный контейнер 1060px, журнальная двухколоночная сетка ленты, навигация.
- **Мобильные устройства:** Одноколоночная лента на 100% ширины, крупные сенсорные области (touch-target от 44px), отсутствие лишних кнопок сверху и снизу (чистый экран).

---

## 🚀 Реализованный функционал

1. **Шапка сайта (Header):**
   - Логотип «Дневник Арчи 🐾» с анимированной лапкой.
   - Навигация: Главная, Галерея фото, Видеохроники, Любимые.

2. **Профиль питомца (Hero-секция):**
   - Круглый аватар Арчи со статусом («На связи 🌿»).
   - Имя, порода, возраст, био/статус.
   - Живые счетчики публикаций и суммарных «лапок» (лайков).
   - Модальное окно «Редактировать» с мгновенным обновлением профиля и сменой фото.

3. **Создание публикаций (Лаконичный креатор):**
   - Только поле ввода текста и кнопка с плюсиком `+ Добавить фото / видео`.
   - **Мультизагрузка:** можно выбрать сразу несколько фотографий и видеороликов (или добавлять их по очереди).
   - Лента предпросмотра прикрепленных медиа с возможностью удаления любого файла по отдельности.
   - Мгновенная публикация в начало ленты.

4. **Инстаграм-карусель медиафайлов в публикациях:**
   - Если к посту прикреплено несколько фото или видео — автоматически включается карусель в стиле Instagram.
   - Перелистывание кнопками-стрелками (`‹` и `›`), сенсорными свайпами на телефонах и точками-индикаторами.
   - Счетчик слайдов в правом верхнем углу (`1 / 3`).
   - Автоматическая пауза видеороликов при переключении слайдов.
   - Полноэкранный **Lightbox** при клике на фотографии.

5. **Кастомный HTML5 видеоплеер:**
   - Большая кнопка воспроизведения в центре.
   - Карамельная полоса прогресса с перемоткой.
   - Таймкод, регулятор звука и полноэкранный режим.

6. **Реакции и комментарии:**
   - Реакция «🐾 Дай лапу!» с анимацией взлетающих лапок.
   - Раскрывающийся блок комментариев с мгновенным добавлением.

7. **Хранение данных в `localStorage`:**
   - Все посты, фото/видео, реакции и изменения сохраняются в браузере.
   - Демо-данные по умолчанию (осенний забег с фото и сонный субботний отдых с видео).
